# Тема 21. Сравнение бесконечно малых. Главная часть, порядок малости и роста (л. 7–8, сл. 25–31)

РК: A19 (одного порядка), A20 (несравнимые), A21 (эквивалентные), A22 (порядок малости одной функции относительно другой); задачи типа 2 (главная часть, порядки, сравнение).

## Определения (дословно по слайдам)

Пусть $f(x)$ и $g(x)$ — две б.м.ф. при $x\to x_0$.

**Определение 1.** Б.м.ф. $f(x)$ и $g(x)$ называют **сравнимыми** при $x\to x_0$, если существует один из пределов: $\lim\limits_{x\to x_0}\dfrac{f(x)}{g(x)}$ или $\lim\limits_{x\to x_0}\dfrac{g(x)}{f(x)}$. Далее будем рассматривать первый предел.

**Определение 2.** Б.м.ф. $f(x)$ и $g(x)$ называют **несравнимыми** при $x\to x_0$, если $\lim\limits_{x\to x_0}\dfrac{f(x)}{g(x)}$ не существует.

**Определение 3.** Б.м.ф. $f(x)$ имеет **высший порядок малости** (в.п.м.) по сравнению с б.м.ф. $g(x)$ при $x\to x_0$, если $\lim\limits_{x\to x_0}\dfrac{f(x)}{g(x)}=0$. Обозначение: $f(x)=o\bigl(g(x)\bigr)$ при $x\to x_0$.

**Определение 4.** Б.м.ф. $g(x)$ имеет высший порядок малости по сравнению с б.м.ф. $f(x)$ при $x\to x_0$, если $\lim\limits_{x\to x_0}\dfrac{f(x)}{g(x)}=\infty$. Обозначение: $g(x)=o\bigl(f(x)\bigr)$ при $x\to x_0$.

**Определение 5.** Б.м.ф. $f(x)$ и $g(x)$ называют **б.м.ф. одного порядка малости** при $x\to x_0$, если существует конечный предел $\lim\limits_{x\to x_0}\dfrac{f(x)}{g(x)}=a\ne0$. Обозначение: $f(x)=O\bigl(g(x)\bigr)$, $g(x)=O\bigl(f(x)\bigr)$ при $x\to x_0$.

**Определение 6.** Б.м.ф. $f(x)$ и $g(x)$ называют **эквивалентными** при $x\to x_0$, если $\lim\limits_{x\to x_0}\dfrac{f(x)}{g(x)}=1$. Обозначение: $f(x)\sim g(x)$ при $x\to x_0$.

**Определение 7.** Число $k$ называется **порядком малости** б.м.ф. $f(x)$ относительно б.м.ф. $g(x)$ при $x\to x_0$, если существует конечный предел $\lim\limits_{x\to x_0}\dfrac{f(x)}{g^k(x)}=a\ne0$, где $k>0$ — порядок малости.

> **Расхождение со слайдами.** **Опр. 2 и пример (сл. 26).** (а) По опр. 1 сравнимы, если существует **хотя бы один** из пределов $\frac fg$, $\frac gf$; согласованная формулировка опр. 2 [не из лекций]: «несравнимы, если не существует ни конечного, ни бесконечного предела $\frac{f}{g}$» (тогда не существует и предела $\frac gf$). (б) В примере лектора $g(x)=x\sin\frac1x$ обращается в $0$ в точках $\frac1{\pi n}\to0$, так что $\frac fg$ не определено ни в какой проколотой окрестности нуля. Корректный пример [не из лекций]: $f=x$, $g=x\left(2+\sin\frac1x\right)$: $\frac fg=\frac1{2+\sin\frac1x}$ — определено, предела не имеет (колеблется между $\frac13$ и $1$).
>
> **Расхождение со слайдами.** **Обозначение $O$.** У лектора $f=O(g)$ — «одного порядка» ($\lim\frac fg=a\ne0$). Во многих учебниках $O(g)$ означает более слабое «$\frac fg$ ограничено». **На РК** при вопросе «одного порядка» писать словами и через предел; знак $O$ — как у лектора.

Таблица (сводка) — для $\lim\limits_{x\to x_0}\frac{f(x)}{g(x)}$:

| Предел $\frac fg$ | Вывод | Запись |
|---|---|---|
| $0$ | $f$ — в.п.м. по сравнению с $g$ | $f=o(g)$ |
| $\infty$ | $g$ — в.п.м. по сравнению с $f$ | $g=o(f)$ |
| $a\ne0$, конечный | одного порядка | $f=O(g)$ |
| $1$ | эквивалентны | $f\sim g$ |
| не существует ($0$, $\infty$, число — нет) | несравнимы | — |

## Главная часть и порядок малости относительно $x-x_0$ [не из лекций — раздел для задач типа 2]

**Определение.** Пусть $f(x)$ — б.м.ф. при $x\to x_0$ ($x_0$ — число). Если
$$f(x)\sim C(x-x_0)^k\quad\text{при }x\to x_0,\qquad C\ne0,\ k>0,$$
т. е. $\lim\limits_{x\to x_0}\dfrac{f(x)}{C(x-x_0)^k}=1$, то $C(x-x_0)^k$ называется **главной частью** $f$, а $k$ — **порядком малости $f$ относительно $x-x_0$**.

Связь с лекцией: это опр. 7 при $g(x)=x-x_0$: $\lim\frac{f(x)}{(x-x_0)^k}=C\ne0$. Для $x_0=0$: главная часть $Cx^k$.

**При $x\to\infty$, б.м.ф.:** если $f(x)\sim Cx^\alpha$, $C\ne0$, то $\alpha<0$; порядок малости относительно $\frac1x$ равен $k=-\alpha$ ($Cx^\alpha=\frac{C}{x^k}$).

**Порядок роста б.б.ф.:**
- При $x\to\infty$: если $f(x)\sim Cx^k$, $C\ne0$, $k>0$, то $Cx^k$ — главная часть, $k$ — **порядок роста** относительно $x$.
- При $x\to x_0$: если $f(x)\sim\dfrac{C}{(x-x_0)^k}=C(x-x_0)^{-k}$, $k>0$ — порядок роста относительно $\frac1{x-x_0}$ (в формате задачи: $C(x-x_0)^\alpha$ с $\alpha=-k<0$).

**Сравнение б.б.ф.** [не из лекций, по аналогии с опр. 3–6]: если $\lim\frac fg=\infty$ — $f$ имеет **высший порядок роста**; $a\ne0$ — одного порядка роста; $1$ — эквивалентны. Через главные части: больше порядок роста — «быстрее» растёт.

**Как сравнивать по главным частям:** если $f\sim C_1(x-x_0)^{k_1}$, $g\sim C_2(x-x_0)^{k_2}$ (б.м.), то
$$\frac fg\sim\frac{C_1}{C_2}(x-x_0)^{k_1-k_2}\to\begin{cases}0,&k_1>k_2\ (f=o(g)),\\ \frac{C_1}{C_2},&k_1=k_2\ (\text{одного порядка};\ \sim\text{ при }C_1=C_2),\\ \infty,&k_1<k_2\ (g=o(f)).\end{cases}$$

## Алгоритм задачи типа 2 (а — б.м./б.б., б — главная часть и порядок, в — сравнение)

**а) Тип.** Подставить предельную точку: $\lim f=0$ — б.м.; $\lim f=\infty$ — б.б. Записать предел явно.

**б) Главная часть.**
1. Если $x_0\ne0$ и $x_0\ne\infty$ — замена $t=x-x_0\to0$ (ищем $Ct^k$).
2. Если $x\to\infty$ — выделять старшие степени $x$ (для б.м. при $x\to\infty$ — замена $t=\frac1x\to0$ удобна).
3. Представить $f$ как **произведение/частное** множителей; каждый множитель заменить эквивалентным (таблица темы 22) или вынести константу (множитель $\to$ число $\ne0$).
4. Если $f$ — **сумма** слагаемых разных порядков — оставить слагаемое низшего порядка малости / высшего порядка роста (теорема 2 темы 22). Если порядки одинаковы — сложить главные части; если они **сокращаются** — нужна большая точность (переписать $f$ иначе).
5. Записать: $f\sim C(x-x_0)^k$; $C=\dots$, порядок малости (роста) $=k$.
6. Проверка: $\lim\frac{f}{C(x-x_0)^k}=1$.

**в) Сравнение.** Сравнить порядки: см. формулу выше. Записать вывод словами и символами ($f=o(g)$, одного порядка, $\sim$). Если одна функция б.м., а другая б.б. — сравнивать нельзя (разные типы).

## Разобранные примеры

**Пример 1.** $\alpha=1-\cos x$, $\beta=x\sin x$, $x\to0$.

<details><summary>Решение</summary>

а) $\alpha\to1-1=0$, $\beta\to0\cdot0=0$ — обе б.м.
б) $\alpha\sim\frac{x^2}2$: $C=\frac12$, $k=2$. $\ \beta=x\cdot\sin x\sim x\cdot x=x^2$: $C=1$, $k=2$.
в) $\frac\alpha\beta\to\frac12\ne0$ — одного порядка, не эквивалентны.
</details>

**Пример 2 (точка $\ne0$).** $f=x^3-3x+2$, $x\to1$.

<details><summary>Решение</summary>

$f(1)=0$ — б.м. Разложение: $x^3-3x+2=(x-1)^2(x+2)$; $x+2\to3$. Главная часть $3(x-1)^2$, порядок малости $2$.
</details>

**Пример 3 ($x\to\infty$, б.б. и б.м.).** $f=\sqrt{x^3+1}+x$, $g=\dfrac1{x^2+1}$, $x\to\infty$ (для $f$ — $x\to+\infty$).

<details><summary>Решение</summary>

$f$: $\sqrt{x^3+1}=x^{3/2}\sqrt{1+x^{-3}}\sim x^{3/2}$; $x=o(x^{3/2})$ — по теореме 2 (для б.б.) $f\sim x^{3/2}$: б.б., порядок роста $\frac32$, главная часть $x^{3/2}$.
$g$: $\frac1{x^2+1}\sim\frac1{x^2}=x^{-2}$: б.м., порядок малости $2$ относительно $\frac1x$, главная часть $1\cdot x^{-2}$.
Сравнивать $f$ и $g$ нельзя — разные типы.
</details>

**Пример 4 (несравнимые).** $f=x$, $g=x\left(2+\sin\frac1x\right)$, $x\to0$.

<details><summary>Решение</summary>

$|g|\le3|x|\to0$ — б.м. $\frac fg=\frac1{2+\sin\frac1x}$: на $x_n=\frac1{\pi n}$ равно $\frac12$, на $x_n=\frac1{\frac\pi2+2\pi n}$ равно $\frac13$ — по Гейне предела нет (ни конечного, ни бесконечного) — несравнимы.
</details>

Задачи 2.1–2.3 и задача 4 типового варианта — в «Решениях РК».

## Типичные ошибки
- Оставлять в главной части множитель, стремящийся к числу: его надо **заменить числом** ($x+2\to3$).
- При $x_0\ne0$ искать главную часть вида $Cx^k$ — нужна $C(x-x_0)^k$.
- Сравнивать б.м. с б.б.
- Для б.б. писать «порядок малости» — это порядок роста.
- Считать «одного порядка» и «эквивалентны» синонимами: эквивалентность — частный случай с $a=1$.
- В сумме одного порядка складывать главные части, не проверив, что они не сокращаются.

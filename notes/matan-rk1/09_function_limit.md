# Тема 9. Предел функции по Коши и по Гейне (л. 3–4, сл. 15–22)

## Определения

Пусть функция $y=f(x)$ определена в окрестности точки $x_0$, за исключением, может быть, самой точки $x_0$.

**Определение 1.** Окрестность, из которой исключена точка $x_0$, называется **проколотой окрестностью** этой точки:
$$\overset{\circ}{S}(x_0)=S(x_0)\setminus\{x_0\}.$$

**Определение 2 (предел функции по Коши, или на языке $\varepsilon,\delta$).** Число $a$ называется пределом функции $y=f(x)$ при $x\to x_0$, если для любого сколь угодно малого положительного числа $\varepsilon$ существует такое достаточно малое число $\delta$, что в проколотой $\delta$-окрестности точки $x_0$ выполнено неравенство $|f(x)-a|<\varepsilon$:
$$\lim_{x\to x_0}f(x)=a\ \overset{def}{\iff}\ \forall\varepsilon>0\ \exists\delta(\varepsilon)>0:\ \forall x\in\overset{\circ}{S}_\delta(x_0)\Rightarrow|f(x)-a|<\varepsilon.$$
$x_0$ называется **предельной точкой**.

Различные формы записи условия на $x$:
$$\forall x\in\overset{\circ}{S}_\delta(x_0)\iff\forall x:\ 0<|x-x_0|<\delta\iff\forall x,\ x\ne x_0:\ |x-x_0|<\delta.$$

**Геометрический смысл:** если значения $x$ попадают в интервал $(x_0-\delta,x_0)\cup(x_0,x_0+\delta)$, то соответствующие значения $y$ функции $y=f(x)$ попадают в интервал $(a-\varepsilon,a+\varepsilon)$.

**Определение 3 (предел функции по Гейне, или на языке последовательностей).** Число $a$ называется пределом функции $y=f(x)$ в точке $x_0$, если для любой последовательности $x_n$ из области определения функции, сходящейся к $x_0$, соответствующая последовательность значений $\{f(x_n)\}$ сходится к $a$:
$$\lim_{x\to x_0}f(x)=a\ \overset{def}{\iff}\ \forall\{x_n\}\in D_f:\ \lim_{n\to+\infty}x_n=x_0\ \Rightarrow\ \lim_{n\to+\infty}f(x_n)=a.$$

> **Расхождение со слайдами.** **Как в слайде 19:** условие $x_n\ne x_0$ не записано. Без него определение Гейне не согласуется с определением Коши, где точка $x_0$ выколота: например, для $f(x)=\begin{cases}1,&x\ne0\\0,&x=0\end{cases}$ по Коши $\lim\limits_{x\to0}f(x)=1$, а постоянная последовательность $x_n=0$ даёт $f(x_n)\to0$. Правильно [не из лекций]:
> $$\forall\{x_n\}:\ x_n\in D_f,\ x_n\ne x_0,\ \lim_{n\to+\infty}x_n=x_0\ \Rightarrow\ \lim_{n\to+\infty}f(x_n)=a.$$

Определения для односторонних пределов, пределов на бесконечности и бесконечных пределов — тема 17 (сводные таблицы).

### Отрицания [не из лекций]

**По Коши** ($a$ не является пределом):
$$\lim_{x\to x_0}f(x)\ne a\iff\exists\varepsilon>0\ \forall\delta>0\ \exists x\in\overset{\circ}{S}_\delta(x_0):\ |f(x)-a|\ge\varepsilon.$$

**По Гейне** ($a$ не является пределом): существует последовательность $x_n\to x_0$, $x_n\ne x_0$, для которой $f(x_n)\not\to a$.

**Предела не существует (рабочий признак по Гейне):** существуют две последовательности $x_n'\to x_0$, $x_n''\to x_0$ ($x_n',x_n''\ne x_0$) такие, что
$$\lim_{n\to\infty}f(x_n')=A,\quad\lim_{n\to\infty}f(x_n'')=B,\quad A\ne B;$$
либо одна последовательность $x_n\to x_0$, для которой $f(x_n)$ не имеет предела.

## Теоремы

**Теорема (эквивалентность определений предела по Коши и по Гейне).** Пределы функции $y=f(x)$ при $x\to x_0$ по Коши и по Гейне эквивалентны.
> **Расхождение со слайдами.** В слайде 22: «…по Коши и по Гейне при $x\to x_0$ **эквивалентности**» — опечатка, «эквивалентны».

В лекции без доказательства. **Идея** [не из лекций]:
- *Коши $\Rightarrow$ Гейне:* для $x_n\to x_0$, $x_n\ne x_0$, по $\delta(\varepsilon)$ найдётся номер, начиная с которого $x_n\in\overset{\circ}{S}_\delta(x_0)$, значит, $|f(x_n)-a|<\varepsilon$.
- *Гейне $\Rightarrow$ Коши:* от противного. Если по Коши $a$ не предел, то $\exists\varepsilon_0\ \forall\delta=\frac1n\ \exists x_n:\ 0<|x_n-x_0|<\frac1n,\ |f(x_n)-a|\ge\varepsilon_0$. Получили $x_n\to x_0$, но $f(x_n)\not\to a$ — противоречие с Гейне.

## Пример из лекции (сл. 21–22): $\lim\limits_{x\to\infty}\cos x$ не существует

$y=\cos x$, $D_f=R$, $\infty$ — предельная точка.

Первая последовательность: $x_n=2\pi n\in D_f$, $n\in\mathbb N$:
$$\lim_{n\to\infty}x_n=\lim_{n\to\infty}2\pi n=2\pi\cdot\lim_{n\to\infty}n=\infty,\qquad\lim_{n\to\infty}\cos(2\pi n)=1,\quad a=1.$$

Вторая последовательность: $x_n=\pi+2\pi n\in D_f$, $n\in\mathbb N$:
$$\lim_{n\to\infty}x_n=\lim_{n\to\infty}(\pi+2\pi n)=\pi+2\pi\cdot\lim_{n\to\infty}n=\pi+\infty=\infty,\qquad\lim_{n\to\infty}\cos(\pi+2\pi n)=-1,\quad a=-1.$$

По теореме о единственности предела приходим к выводу, что $\lim\limits_{x\to\infty}\cos x$ не существует.

> **Расхождение со слайдами.** В слайде 22 ссылка «по теореме о единственности предела **функции**». Эта теорема доказывается позже (сл. 26–31). По сути здесь работает единственность предела **последовательности** (тема 7): если бы $\lim\cos x=a$, то по Гейне $\cos x_n'\to a$ и $\cos x_n''\to a$, откуда $a=1$ и $a=-1$. Концовка слайда «Равенство доказано» — тоже неточность: доказано несуществование предела.

## Алгоритм: доказать, что предела нет (по Гейне)

1. Подобрать две последовательности $x_n'\to x_0$ и $x_n''\to x_0$ (не равные $x_0$), на которых $f$ принимает «удобные» значения — обычно точки, где периодическая функция равна разным числам.
2. Проверить, что обе стремятся к $x_0$.
3. Посчитать $\lim f(x_n')=A$ и $\lim f(x_n'')=B$.
4. Если $A\ne B$ — предела нет (по Гейне и единственности предела последовательности).

## Примеры

**Пример 1.** $\lim\limits_{x\to0}\sin\dfrac1x$ не существует.

<details><summary>Решение</summary>

$x_n'=\dfrac1{\pi n}\to0$: $\ \sin\dfrac1{x_n'}=\sin\pi n=0\to0$.

$x_n''=\dfrac1{\frac\pi2+2\pi n}\to0$: $\ \sin\dfrac1{x_n''}=\sin\left(\dfrac\pi2+2\pi n\right)=1\to1$.

$0\ne1$, значит, предела нет.
</details>

**Пример 2 (по определению Коши) [не из лекций].** Доказать $\lim\limits_{x\to2}(3x-1)=5$.

<details><summary>Решение</summary>

$|f(x)-a|=|3x-1-5|=3|x-2|<\varepsilon\iff|x-2|<\dfrac\varepsilon3$. Берём $\delta(\varepsilon)=\dfrac\varepsilon3$: $\ \forall x:\ 0<|x-2|<\delta\Rightarrow|3x-1-5|<\varepsilon$.
</details>

## Типичные ошибки

- В определении Гейне забывать условие $x_n\ne x_0$ (см. расхождение к слайду 19).
- «Доказывать» существование предела одной последовательностью: по Гейне нужны **все** последовательности. Одна последовательность годится только для опровержения.
- Считать, что предел зависит от $f(x_0)$: по Коши точка $x_0$ выколота, функция там может быть не определена.
- Брать $\delta$, зависящее от $x$: $\delta$ зависит только от $\varepsilon$.

# Задача на плоскости и прямые: с чего начать

Сводка приёмов для задач 416–466. Почти любая задача сводится к двум вопросам: **какая точка** и **какой вектор** (нормаль плоскости или направление прямой). Ниже — где их брать.

## 1. Как получить нужный вектор

| Дано | Нормаль плоскости $\vec n$ / направление прямой $\vec s$ |
|---|---|
| плоскость $Ax+By+Cz+D=0$ | $\vec n=\{A,B,C\}$ |
| прямая $\frac{x-x_0}l=\frac{y-y_0}m=\frac{z-z_0}n$ | $\vec s=\{l,m,n\}$ |
| прямая как пересечение плоскостей | $\vec s=\vec n_1\times\vec n_2$ |
| плоскость параметрически $M_0+u\vec a+v\vec b$ | $\vec n=\vec a\times\vec b$ |
| плоскость ⊥ прямой | $\vec n=\vec s$ |
| плоскость ⊥ двум плоскостям | $\vec n=\vec n_1\times\vec n_2$ |
| плоскость через две точки $A,B$ и ⊥ плоскости $\vec n_1$ | $\vec n=\overrightarrow{AB}\times\vec n_1$ |
| плоскость через прямую $(\vec s)$ ⊥ плоскости $(\vec n_1)$ (проектирующая) | $\vec n=\vec s\times\vec n_1$ |
| плоскость через прямую $(M_0,\vec s)$ и точку $M_1$ | $\vec n=\vec s\times\overrightarrow{M_0M_1}$ |
| плоскость через три точки | $\vec n=\overrightarrow{AB}\times\overrightarrow{AC}$ |
| общий перпендикуляр двух прямых | $\vec s=\vec s_1\times\vec s_2$ |

## 2. Типовые построения

**Основание перпендикуляра из точки $P$ на плоскость** $Ax+By+Cz+D=0$:
$$H=P-\frac{f(P)}{|\vec n|^2}\,\vec n,\qquad f(P)=Ax_P+By_P+Cz_P+D.$$

**Основание перпендикуляра из $P$ на прямую** $M_0+t\vec s$:
$$t^*=\frac{\overrightarrow{M_0P}\cdot\vec s}{|\vec s|^2},\qquad H=M_0+t^*\vec s.$$

**Симметричная точка** относительно плоскости или прямой: $P'=2H-P$ (основание $H$ — середина $PP'$).

**Проекция прямой на плоскость:** проектирующая плоскость (через прямую, нормаль $\vec s\times\vec n$) в системе с данной плоскостью.

**Точка пересечения прямой и плоскости:** подставить параметрические уравнения прямой в уравнение плоскости, найти $t$.

**Минимум суммы расстояний $|MA|+|MB|$, $M$ на плоскости** (задача 434): если $A,B$ по одну сторону (знаки $f(A),f(B)$ одинаковы), отразить $A$ в $A'$ и взять пересечение $A'B$ с плоскостью; если по разные — пересечение $AB$ с плоскостью.

## 3. Расстояния и углы — какую формулу брать

| Что | Формула |
|---|---|
| точка — плоскость | $\dfrac{|Ax_0+By_0+Cz_0+D|}{\sqrt{A^2+B^2+C^2}}$ |
| плоскость — параллельная плоскость | привести к одинаковым $A,B,C$; $\dfrac{|D_1-D_2|}{|\vec n|}$ |
| точка — прямая | $\dfrac{|\overrightarrow{M_0M_1}\times\vec s|}{|\vec s|}$ |
| прямая — прямая (скрещиваются) | $\dfrac{|\vec s_1\vec s_2\overrightarrow{M_1M_2}|}{|\vec s_1\times\vec s_2|}$ |
| прямая — прямая (параллельны) | от точки одной до другой прямой |
| угол плоскостей | $\cos\varphi=\frac{|\vec n_1\cdot\vec n_2|}{|\vec n_1||\vec n_2|}$ |
| угол прямых | $\cos\varphi=\frac{|\vec s_1\cdot\vec s_2|}{|\vec s_1||\vec s_2|}$ |
| угол прямой и плоскости | $\sin\varphi=\frac{|\vec s\cdot\vec n|}{|\vec s||\vec n|}$ |

## 4. Пучок, биссекторы, острый/тупой угол

- «Плоскость через линию пересечения $\Pi_1,\Pi_2$ и …» — пучок $\alpha\Pi_1+\beta\Pi_2=0$, оставшееся условие даёт $\alpha:\beta$. Не забудь проверить сами $\Pi_1$ и $\Pi_2$ (случай $\beta=0$ или $\alpha=0$).
- Биссекторы: $\dfrac{f_1}{|\vec n_1|}=\pm\dfrac{f_2}{|\vec n_2|}$.
- Точка $M$ в **остром** угле $\iff f_1(M)f_2(M)(\vec n_1\cdot\vec n_2)<0$.
- Биссектор угла, содержащего точку $M$: знак в $\pm$ выбрать так, чтобы $\frac{f_1(M)}{|\vec n_1|}$ и $\pm\frac{f_2(M)}{|\vec n_2|}$ были одного знака.

## 5. Проверка ответа (30 секунд, но спасает баллы)
1. Подставь заданные точки в найденное уравнение — должны обнулять.
2. Проверь перпендикулярность/параллельность через скалярное или векторное произведение.
3. Расстояние не может быть отрицательным, косинус угла между плоскостями — больше 1.

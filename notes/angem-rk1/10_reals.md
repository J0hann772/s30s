## Аксиомы поля
Множество $\mathbb F$ с бинарными операциями $+$ и $\cdot$ — **поле**, если $\forall a,b,c\in\mathbb F$:

| № | Аксиома | Школьное название | Научный термин |
|---|---|---|---|
| 1.1 | $(a+b)+c=a+(b+c)$ | сочетательный закон сложения | ассоциативность |
| 1.2 | $\exists0\in\mathbb F:\ a+0=0+a=a$ | свойство нуля | нейтральный элемент |
| 1.3 | $\exists(-a)\in\mathbb F:\ a+(-a)=(-a)+a=0$ | противоположное число | противоположный элемент |
| 1.4 | $a+b=b+a$ | переместительный закон сложения | коммутативность |
| 2.1 | $(ab)c=a(bc)$ | сочетательный закон умножения | ассоциативность |
| 2.2 | $\exists1\in\mathbb F:\ 1\cdot a=a\cdot1=a$ | свойство единицы | нейтральный элемент |
| 2.3 | $a\ne0\ \Rightarrow\ \exists a^{-1}\in\mathbb F:\ aa^{-1}=a^{-1}a=1$ | взаимно обратное число | обратный элемент |
| 2.4 | $ab=ba$ | переместительный закон умножения | коммутативность |
| 3 | $a(b+c)=ab+ac$ | распределительный закон | дистрибутивность |

> **Неточность в конспекте.** Во втором файле у аксиомы 2.4 ($a\cdot b=b\cdot a$) написано «переместительный закон **сложения**». Правильно: умножения.

## Аксиомы порядка

| № | Аксиома | Название |
|---|---|---|
| 1.1 | $a\le a$ | рефлексивность |
| 1.2 | $(a\le b)\wedge(b\le a)\Rightarrow a=b$ | антисимметричность |
| 1.3 | $(a\le b)\wedge(b\le c)\Rightarrow a\le c$ | транзитивность |
| 2.1 | $a\le b\Rightarrow a+c\le b+c$ | связь порядка со сложением |
| 2.2 | $(0\le a)\wedge(0\le b)\Rightarrow0\le ab$ | связь порядка с умножением |

1.1–1.3 — аксиомы порядка; 2.1 и 2.2 связывают порядок с операциями. Для вещественных чисел порядок ещё и **линейный**: любые два числа сравнимы [не из конспекта].

## Аксиома непрерывности
Для непустых $A,B\subseteq X$ пишут $A\le B$, если $a\le b$ для всех $a\in A$, $b\in B$.
$$A\le B\ \Longrightarrow\ \exists c\in X:\ A\le\{c\}\le B.$$

**Множество вещественных чисел** $\mathbb R$ — упорядоченное поле с аксиомой непрерывности. Рациональные числа ей не удовлетворяют: между множествами $\{x\in\mathbb Q:\ x^2<2,\ x>0\}$ и $\{x\in\mathbb Q:\ x^2>2,\ x>0\}$ нет рационального разделяющего числа [не из конспекта].

# s30s

Небольшой личный учебный проект: сайт с конспектами для подготовки к контрольным (сейчас матанализ и аналитическая геометрия, РК1).
Конспекты на markdown с формулами, тренировочные варианты с таймером, карточки, поиск, отметки прогресса. Бэкенда нет, всё статика.

**Стек:** чистые HTML/CSS/JS без сборщика и npm, KaTeX (лежит в `vendor/`), Python-скрипты для сборки данных, nginx + Docker для выкладки.

## Демо

Сайт можно попробовать вживую: https://s30s.ru

## Как открыть локально

Двойной клик по `index.html`. Работает с `file://`, без сервера и без интернета.

Через Docker:

```
docker compose up -d --build
```

Сайт откроется на http://localhost:8080. Подробнее про контейнер — в [DOCKER.md](DOCKER.md).

## Структура

```
index.html, style.css     страница и стили
app.js                    markdown-рендерер, навигация, поиск, прогресс, карточки, вариант с таймером
widgets.js                интерактивные иллюстрации в конспектах
manifest.js               список предметов и контрольных
data/                     собранные данные контрольных (генерируются из notes/)
notes/<id>/               конспекты в markdown и exam.json
materials/                сжатые фото и PDF, архивы для скачивания
tools/                    скрипты сборки
server/                   конфиги nginx
vendor/katex/             KaTeX для офлайн-работы
sw.js                     service worker для работы без сети
```

## Правка конспектов

1. Поправить файл в `notes/<id>/`.
2. Пересобрать данные:

   ```
   python tools/build_exam.py notes/angem-rk1 data/angem-rk1.js
   python tools/build_data.py notes/matan-rk1 notes/matan-rk1/93_block_b_figs.json data/matan-rk1.js
   ```

3. Обновить страницу.

Формат конспекта: обычный markdown, формулы в `$...$` и `$$...$$`, решения прячутся в `<details>`.

## Новая контрольная

За образец берётся `notes/angem-rk1/`:

1. Создать `notes/<id>/` с `exam.json` (темы, блоки вопросов, тренировочный вариант) и markdown-файлами тем.
2. Собрать: `python tools/build_exam.py notes/<id> data/<id>.js`. Сборщик проверяет ссылки между темами, вопросами и задачами.
3. Материалы (PDF, фото) положить в `materials-src/<id>/NN_Группа/` и выполнить `python tools/build_materials.py <id>` (нужен Pillow). Папка `materials-src/` в git не попадает.
4. Добавить запись в `manifest.js`.

## Прогресс и localStorage

Отметки хранятся только в браузере, ключи с префиксом id контрольной (`matan-rk1:topic:...`).
Если в `manifest.js` поставить `progress: false`, отметки отключатся и ничего не будет записываться.
Аккаунтов, cookie и запросов на сервер нет.

## Работа без сети

Service worker кэширует сайт и материалы после первого визита. Нужен HTTPS (на `localhost` тоже работает).
Если заменить фото под тем же именем, нужно поднять версию кэша `SW_CACHE` в `sw.js` и `app.js`.

## Ограничения

- Общие темы между контрольными пока копируются, а не переиспользуются.
- Расхождения со слайдами хранятся и в тексте темы, и отдельным списком, при правке менять оба места.
- Markdown-рендерер самописный и понимает только нужное подмножество: заголовки, списки, таблицы, цитаты, код, ссылки.
